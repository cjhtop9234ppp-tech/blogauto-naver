# 설정값과 환경변수

## 일반 설정

저장 파일: `%APPDATA%\blogauto-naver-tistory\runtime\user-settings.json`

| 설정명 | 목적 | 필수 | 공개 가능 |
|---|---|---:|---:|
| `blogId` | 네이버 블로그 ID | 발행 시 필요 | 예 |
| `category` | 일반 작업 기본 카테고리 | 선택 | 예 |
| `keyword` | 검색 키워드 | 검색 모드에서 선택 | 예 |
| `topic` | 수동 주제 | 수동 모드에서 선택 | 예 |
| `sourceMode` | `research` 또는 `file_upload` | 아니오 | 예 |
| `sourceFilePaths` | 업로드 원본 경로 | 파일 모드에서 필요 | 경로 주의 |
| `codexCmdPath` | Codex 실행파일 경로 | 실행 시 필요 | 경로만 |
| `codexModel` | 모델 ID | 아니오 | 예 |
| `primarySearchProvider` | 기본 검색 제공자 | 아니오 | 예 |
| `fallbackSearchProvider` | 보조 검색 제공자 | 아니오 | 예 |
| `publishVisibility` | 공개/비공개 | 발행 시 필요 | 예 |
| `publishScheduleMode` | 즉시/예약 | 발행 시 필요 | 예 |
| `publishAfterGenerate` | 생성 후 발행 여부 | 아니오 | 예 |
| `publishToTistoryAfterNaver` | Naver 성공 후 Tistory 발행 | 아니오 | 예 |
| `includeTitleImage` | 제목 이미지 생성 여부 | 아니오 | 예 |
| `maxBodyImages` | 본문 이미지 사용 여부/안전 상한 | 아니오 | 예 |
| `agentModels` | Main/Research/Writer/Image 모델 설정 | 아니오 | 예 |

## 계정·카테고리

저장 파일: `%APPDATA%\blogauto-naver-tistory\runtime\account-categories.json`

계정에는 표시명, Blog ID, 카테고리, 이미지 스타일 정보, 세션 상태가 저장됩니다. 네이버 비밀번호는 저장하지 않으며, 구형 파일에 비밀번호 필드가 있으면 읽는 과정에서 제거하도록 되어 있습니다.

카테고리에는 이름, 키워드, 제외 주제, 발행 목적, 문체, 최신성, 검색 채널, 검색 제공자, 블로그 신뢰 설정이 들어갑니다.

## 세션·브라우저

Chrome 프로필은 runtime의 `browser-profiles/` 아래에 저장됩니다. 쿠키와 세션은 민감정보이므로 GitHub와 문서에 포함하지 않습니다.

## 작업·복구 데이터

```text
runtime/blog_history.jsonl
runtime/jobs/job_<id>/job-input.json
runtime/jobs/job_<id>/job-checkpoint.json
runtime/jobs/job_<id>/agent-result.json
runtime/recovery-playbook.json
runtime/history-publish-failures.json
```

체크포인트에 프롬프트가 저장될 수 있지만 비밀번호·토큰·쿠키·자격증명은 `sanitizeResumeInput()`에서 제외하도록 설계되어 있습니다.

## 비밀값 검사 원칙

실제 네이버 ID/비밀번호, Cookie, Session, API Key, 토큰은 문서에 기록하지 않습니다. 현재 코드에서 네이버 자동 로그인 비밀번호 저장·입력은 의도적으로 제거된 상태입니다. 검색이나 Codex 인증은 사용자 PC의 외부 로그인·실행환경에 의존하므로 실제 인증값은 별도로 확인해야 합니다.
