# 버전 변경 이력

## 0.1.0

현재 `package.json`에 기록된 프로그램 버전입니다.

### 현재 소스에서 확인되는 기능 범위

- Naver Blog 생성·발행
- Tistory 후속 발행 및 테스트 발행
- 계정별 카테고리·검색 설정
- TXT/MD/PDF/DOCX/XLSX/XLS/CSV/PPTX 원본 파싱
- Research/Title, Writer, Main Review, Image Worker
- Naver 수동 로그인 세션 재사용
- 작업 이력 필터·일괄 발행·성공 처리·삭제·카테고리 일괄 적용
- 작업 단계 체크포인트와 복구 프롬프트
- 온새카 회원마당 수집·9개 슬롯 계획·승인 흐름
- Windows 09:00/10:30/12:00 스케줄러 흐름

### 검증 경계

세부 기능이 언제 추가되었는지는 현재 작업 트리의 커밋·릴리스 이력만으로 다시 대조해야 합니다. 파일명에 `final`, `latest`, `fix`가 포함된 과거 `dist-*` 폴더는 공식 버전 이력으로 간주하지 않습니다.

## 변경 기록 작성 규칙

향후 변경 시 다음을 기록합니다.

```text
버전 / 날짜 / 변경 목적 / 변경 파일 / 검사 결과 / 설치파일 해시 / 알려진 제한
```
