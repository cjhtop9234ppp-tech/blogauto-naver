# 버전 변경 이력

## 0.1.1 - 2026-09-16

### 온새카 이미지 누락 수정

- 랜덤 주제 온새카 등록 단계에서 생성된 제목·본문 이미지 경로를 실제 첨부 목록으로 전달합니다.
- 존재하지 않는 이미지 파일은 등록 전에 감지하고, 이미지 누락 상태로 성공 처리하지 않습니다.
- 온새카 첨부 입력칸이 여러 파일을 지원하지 않으면 등록을 중단하고 원인을 기록합니다.
- 이미지 첨부 준비 개수와 실패 원인을 작업 로그에 남깁니다.

### 검증 범위

- 자동 문법·회귀 검사 통과 후 별도 portable EXE로 빌드합니다.
- 온새카 실제 로그인 상태에서의 본문 인라인 표시 여부는 사이트 편집기 구조에 따라 별도 확인이 필요합니다. 이번 버전은 우선 첨부파일 전달과 누락 차단을 보장합니다.

## 0.1.0

현재 `package.json`에 기록된 프로그램 버전입니다.

### 현재 소스에서 확인되는 기능 범위

- Naver Blog 생성·발행
- Tistory 후속 발행 및 테스트 발행
- 계정별 카테고리·검색 설정
- TXT/MD/PDF/DOCX/XLSX/XLS/CSV/PPTX 원본 파싱
- Research/Title, Writer, Main Review, Image Worker
- Naver 수동 로그인 세션 재사용
- 작업 이력 필터·일괄 발행·성공 처리·삭제·카테고리 일괄 적용
- 작업 단계 체크포인트와 복구 프롬프트
- 온새카 회원마당 수집·9개 슬롯 계획·승인 흐름
- Windows 09:00/10:30/12:00 스케줄러 흐름

### 검증 경계

세부 기능이 언제 추가되었는지는 현재 작업 트리의 커밋·릴리스 이력만으로 다시 대조해야 합니다. 파일명에 `final`, `latest`, `fix`가 포함된 과거 `dist-*` 폴더는 공식 버전 이력으로 간주하지 않습니다.
