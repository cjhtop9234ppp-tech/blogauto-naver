# 설치 및 실행 방법

## 확인된 방식

`package.json`의 현재 버전은 `0.1.0`이고 Windows portable 빌드를 사용합니다.

```json
"dist": "electron-builder --win portable && node scripts/prepare-dist-runtime.js"
```

현재 폴더에는 과거 NSIS `Setup.exe` 산출물도 남아 있지만, 현재 package 설정의 공식 재현 경로는 portable입니다. 따라서 어떤 파일이 최신인지 파일명만 보고 판단하면 안 됩니다.

## 개발 환경 실행

```powershell
Set-Location 'C:\Users\MYCOM\Documents\ChatGPT\네이버 블로그 자동화(Codex 프로그램 소스코드)\blogauto-naver'
npm install
npm start
```

## 검사

```powershell
npm run check
npm run check:file-parser
```

Electron GUI는 실행 환경에 따라 표시되지 않을 수 있으므로 `npm start`의 종료 코드만으로 화면 동작을 확정하지 않습니다. `scripts/smoke-electron.js`와 실제 UI 확인을 함께 사용해야 합니다.

## 빌드

```powershell
npm run dist
```

빌드 결과는 `dist/`에 생성되고 `prepare-dist-runtime.js`가 `dist/runtime` 및 unpacked runtime 기본 폴더를 준비합니다. 기존 `dist`를 삭제하거나 덮어쓰는 작업은 사용자 승인 없이 하지 않습니다. 안전한 검증에서는 별도 output 디렉터리를 사용해야 합니다.

## 최초 실행

1. 실행파일 또는 개발 실행으로 프로그램을 엽니다.
2. 계정에 네이버 Blog ID와 카테고리를 등록합니다.
3. 네이버 비밀번호는 프로그램에 저장하지 않습니다.
4. 세션 확인 또는 발행 중 열린 Chrome에서 직접 로그인·보안 확인을 합니다.
5. 일반 작업은 파일 업로드 또는 검색 입력을 선택합니다.
6. Preview와 Main 검수 결과를 확인합니다.
7. 승인된 경우 발행을 실행합니다.

## 사용자 데이터 보존

설치파일을 교체해도 사용자 데이터는 `%APPDATA%\blogauto-naver-tistory\runtime`에 유지되는 것이 기본 설계입니다. 다만 다른 실행파일의 `userData` 경로가 달라지면 계정과 이력이 보이지 않을 수 있으므로, 업데이트 전 런타임 경로를 확인해야 합니다.

## 설치 검증 경계

- 소스 문법·계약 검사: 자동 검사 가능
- portable 파일 생성: 빌드로 확인 가능
- 새 PC 설치 후 로그인·네이버 발행: 사용자 계정과 Chrome 세션이 필요하므로 별도 라이브 검증 필요
- 설치파일의 모든 기능 정상: 현재 문서 생성만으로는 확정할 수 없음
